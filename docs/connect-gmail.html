Google connection is unavailable

The supported SkyTwin technical preview is an isolated, account-free sample. It does not connect Gmail, Google Calendar, or Google identity.

Do not create or paste Google credentials for this preview. Source components from earlier development work do not constitute a supported connection flow, and setting environment variables does not change the packaged preview boundary. Existing stored credentials or tokens are retained rather than silently deleted, but disabled paths do not use them.

What you can use now

Choose the account-free sample in the desktop onboarding flow. It uses fictional data and a session-local interaction surface that cannot reach connectors, credentials, providers, execution adapters, or external effects.

What remains before real Google access

Managed Google identity and Calendar are deferred. Operator/BYO Google is also unsupported until SkyTwin has one reviewed client-generation authority across authorization, callback, token refresh, connector admission, ownership, exact granted capabilities, and action execution.

Secret custody is part of that gate. The existing credential-writer disclosure is: Stored without app-level encryption in SkyTwin's configured database. A supported path must define migration and locked-key behavior rather than treating a five-minute credential walkthrough as sufficient.

Google requirements still apply later

A future BYO or managed flow will remain subject to Google's publishing status, tester restrictions, warning, token-expiry, user-data, verification, and any assigned security-assessment requirements. A successful personal test is not evidence that Google approved a SkyTwin-managed client. See the deferred Google integration plan and Google's current API Services User Data Policy.
